# AskYourDB

AskYourDB lets you ask questions about a SQLite database in plain English. It generates SQL, runs the query, and shows both the SQL and the result.

## Demo

https://askyourdb-bjuekrtwwfgq5dtacgswyy.streamlit.app

## Features

- Ask database questions in plain English
- See the generated SQL and query result
- Browse database tables, columns, and relationships
- Upload a SQLite database for local use
- Add tables, columns, rows, and updates through forms
- Review and confirm write queries before they run
- Keep recent conversation history for follow-up questions

## How it works

```text
User question
    -> Groq generates SQL
    -> sqlglot checks that the SQL is safe
    -> SQLite runs the query
    -> Streamlit shows the SQL and result
```

## Safety checks

- Only one SQL statement is allowed at a time.
- `CREATE`, `DROP`, `ALTER`, and `TRUNCATE` are blocked when generated by the LLM.
- `DELETE` and `UPDATE` without a `WHERE` clause are blocked.
- Other write queries require confirmation before execution.
- Generated SQL must use a real table from the connected database.
- Form-based inserts and updates use parameterized queries.

## Tech stack

## Run locally

1. Create and activate a virtual environment:

```bash
python -m venv venv
venv\Scripts\activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Create a `.env` file in the project root:

```text
GROQ_API_KEY=your_key_here
```

4. Start the app:

```bash
streamlit run app.py
```

## Sample database

The sample database is stored at `data/ecommerce.db` and contains customers, products, orders, and order items.

To recreate the sample data:

```bash
python scripts/create_schema.py
python scripts/generate_data.py
```

## Evaluation

The evaluation script asks sample questions and compares the results with answers calculated by trusted SQL queries.

```bash
python -m tests.eval_set
```

## Privacy and limitations

- Uploaded database schemas and query results are sent to Groq to generate SQL and answer summaries. Do not upload sensitive data.
- This project is designed for local or single-user use. On a public deployment, do not let multiple people upload databases at the same time.
- Some complex or ambiguous questions may generate incorrect SQL.
